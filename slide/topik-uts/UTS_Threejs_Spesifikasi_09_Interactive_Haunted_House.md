# Spesifikasi Teknis UTS — Interactive Haunted House

## Konsep Project
Player menjelajahi rumah berhantu dengan lighting atmosferik, fog, object interaktif, pintu, lampu berkedip, dan event visual.

## Experience Loop
```text
Explore
→ Observe
→ Interact
→ Trigger Event
→ Find Objective
→ Escape / Complete
```

## Fokus Grafika Komputer
- Atmospheric lighting
- Shadow
- Fog
- Emissive effect
- Animated light
- GLB asset
- Environment
- Horror VFX

## Requirement Minimum
- Minimal 2 area/room.
- Minimal 5 interactive object.
- Minimal 1 animated door.
- Minimal 1 flickering light.
- Fog.
- Shadow.
- Minimal 1 GLB.
- Minimal 2 horror VFX.
- Raycasting.
- Objective completion.

## VFX Contoh
- light flicker,
- ghost transparency,
- emissive eyes,
- smoke,
- object shake,
- sudden silhouette.

## Interaction
- Click door.
- Inspect object.
- Activate lamp.
- Collect key.
- Trigger event.

## Lighting
Gunakan kombinasi:
- ambient rendah,
- point/spot light,
- emissive object.

## Win Condition
Temukan object utama atau berhasil keluar dari rumah.

## Challenge Opsional
- Random event.
- Moving ghost.
- Audio trigger.
- Cinematic camera.
- Alternate ending.

## Pembagian Tim
- Anggota 1: house, assets, lighting.
- Anggota 2: interaction, objective, state.
- Anggota 3: fog, animation, horror VFX, HUD.
